# ZovGame — шутер 1 на 1 по Wi-Fi (C++ / NativeActivity / OpenGL ES 3 / AAudio)

Весь код на C++, Java нет (`android:hasCode="false"`). Карта, персонаж и револьвер взяты из твоего `game.zip`,
АК-47 построен процедурно (в архиве его не было), звуки АК и мелочёвка синтезированы, звуки револьвера нарезаны из `r8-revolver-csgo.mp3`.

## Как собрать APK (я в своей среде не мог: там нет Android SDK/NDK и нет интернета)
1. **Android Studio**: открыть папку `android/`, дождаться Sync, `Build > Build APK`. Нужны NDK 26.1 и CMake 3.22 (студия предложит скачать).
2. **GitHub Actions**: залить проект в репозиторий, `Actions > Build APK` — готовый `.apk` в артефактах (`.github/workflows/build.yml`).
3. **Без Gradle**: `export ANDROID_HOME=...; ./tools/build_apk.sh` -> `build/ZovGame.apk` (нужны NDK, cmake, build-tools, zip, keytool).
APK подписан debug-ключом, ставится напрямую. Минимум Android 8.0 (API 26), нужен OpenGL ES 3.0.

## Что есть
* Меню в стиле референса (`Guimenugame.png`): тёмная сцена арены сзади, список слева, «кисть» в заголовке.
* **Игра с ботом** (3 сложности) и **сеть**: «Создать лобби» (хост сразу заходит на карту, 1 минута ожидания, потом отсчёт 5 с) и
  «Найти лобби» (карточки с превью карты и названием; по умолчанию «Новая карта»). Поиск по UDP-broadcast, порты 28281/28282.
* 2 оружия: R8 Револьвер (600$) и АК-47 (2700$), броня (650$). Закупка в стиле CS (категории слева, статы справа), раунды до 7 побед, экономика как в CS.
* Bhop (включается в «Игра»): при удержании прыжка скорость не теряется, в воздухе разгон поворотом + боковым движением (airstrafe).
* HUD: счёт/таймер/раунд, HP/броня, патроны, killfeed, хитмаркер (красный при хедшоте), индикатор урона, баннеры раундов.
* Анимации оружия: покачивание при ходьбе, инерция при повороте, отдача, перезарядка, смена, прыжок/приземление; гильзы с физикой, трассеры, искры, следы от пуль.
* Графика: тени (shadow map 1536², PCF), небо с солнцем, мягкие блики, туман, MSAA 4x (если поддерживается).
* Настройки: чувствительность X/Y, FOV, гироскоп (чувствительность/инверсия), прицел (тип/длина/толщина/зазор/цвет/обводка/прозрачность с предпросмотром),
  соотношение сторон 16:9 / 4:3 / 5:4 / 1:1 + «растянуть на весь экран», FPS, тени, громкость, **редактор кнопок** (перетаскивание, размер, прозрачность, скрытие).

## Что я проверил здесь, а что нет
Проверено на десктопе (`tests/run.sh`): загрузка твоей карты, коллизии/ступеньки/падение, навигационная сетка и поиск пути, матч бота до 7 побед (бот доходит и убивает),
bhop набирает скорость выше обычной (7.6 против 5.7 м/с), UDP: обнаружение лобби, join, синхронизация фаз, выстрел клиента -> урон на хосте -> событие обратно.
Код рендера/UI/Android-слоя проходит проверку компилятором на заглушках GLES/EGL, но **ни разу не запускался на телефоне**: геометрия HUD, ощущения от управления,
положение оружия в руках (таблица `kVm` в `src/app_render.cpp`), чувствительность гироскопа и знак осей могут потребовать подстройки.
Звуки револьвера нарезаны по всплескам громкости, я их не слышал — если порезано криво, поправь `r8_cuts()` в `tools/pack_audio_font.py`.

## Про ассеты
`R8 revolver.obj` и `r8-revolver-csgo.mp3` — материалы Valve (CS:GO). Для личного проекта ок, для публикации/раздачи нужны свои. Папку `hud/cs2-hud-recovery`
(выдрана из внутренней библиотеки чита) я **не использовал**: HUD и шрифты (DejaVu, свободная лицензия) сделаны с нуля. Вторая карта (`shooter map.fbx`) оказалась сценой с человечком и плоскостью, не картой.

## Структура
`src/core` — логика (мир, бот, раунды, сеть, микшер), `src/gfx` — рендерер, `src/app*.cpp` — экраны/HUD/ввод, `src/platform/android_main.cpp` — вход Android,
`tools/` — конвертеры ассетов (FBX/OBJ/PNG/MP3 -> форматы игры), `assets/` — готовые ассеты, `tests/` — тесты логики.
